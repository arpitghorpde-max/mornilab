# Morni Step 5 — delivered features

- Fixed three-stage journey for every skill: Prarambha → Sadhana → Siddhi.
- Founder stage tabs and stage-specific level creation/editing.
- Stage-specific school access with hierarchical permissions.
- Student stage locks enforced by the API, not only the interface.
- Teacher student-review page with the same staged journey.
- Physical project verification: one teacher-uploaded evidence photo + XP + optional note.
- Duplicate level completion blocked so XP cannot be awarded twice.
- Student profile photo managed from the teacher student profile.
- Evidence photos automatically form a level-by-level student portfolio.
- Student dashboard redesigned with XP, progress, achievements and project cards.
- Certificate record issued at every 10 completed levels within a stage.
- Trophy issued when all published levels in a stage are completed.
- YouTube thumbnail shown before the privacy-friendly embedded player is loaded.
- Existing school standard restrictions preserved when changing stage access.
- Existing Step 4 learning images and text fields remain supported.
- New database migration is forward-only during normal upgrade; no seed/reset required.
